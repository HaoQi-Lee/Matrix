# Matrix 数字雨屏保（Windows）

经典《黑客帝国》风格数字雨的 Windows 屏保。灵感来自本仓库的 `screensave.sh`
（Linux 终端版）。单个 C# 源文件，用系统自带的 .NET Framework 编译器构建，
零外部依赖，产物是一个标准的 `Matrix.scr`。

## 构建

要求：Windows 10+（自带 .NET Framework 4.x 即可，无需安装任何东西）。

```bat
build.bat
```

成功后当前目录生成 `Matrix.scr`（约几十 KB）。

## 快速预览

右键 `Matrix.scr` → **测试**，或双击直接运行。

按键 / 点击 / 移动鼠标超过 10 像素即可退出。

## 安装为系统屏保

1. 把 `Matrix.scr` 复制到 `C:\Windows\System32\`（需要管理员权限）。
2. 设置 → 个性化 → 锁屏界面 → 屏幕保护程序设置。
3. 下拉框选择 "Matrix"，设置等待时间 → 确定。

之后系统闲置达到等待时间会自动启动；动一下鼠标或按键即恢复。

## 命令行参数（.scr 标准约定）

| 参数 | 行为 |
|------|------|
| `/s` 或无参数 | 全屏播放 |
| `/c` | 弹出"无设置项"提示 |
| `/p <hwnd>` | 设置面板预览（不支持，直接退出） |
| `/a` | 密码保护（已废弃，直接退出） |
| `/smoke` | 引擎自检：跑 3000 帧并校验列状态不变量与总量带宽，结果写入同目录 `smoke-result.txt` |

## 效果说明

- 字符集：半角片假名（ｱｲｳ…）+ 数字，MS Gothic 字体保证等宽对齐。
- 每列独立：随机长度（8~25 行）与量化速度（8~30 行/秒），流从单字符生长，出屏立即重生、2/3 概率从屏幕中部随机行起步（经典 Win32 数字雨行为）；多显示器各自独立雨场。
- 配色：白色头部，其后绿色按列内位置线性渐隐至黑（64 级）。
- 渲染：经典全帧重画方式 — Bitmap 后缓冲清黑、重画所有可见字元、一次上屏；字元预渲染为黑底精灵并以 SourceCopy 合成。CPU 实测整机约 6.6%（6 核机器，折合单核约 40%）。
- 多显示器：每块屏幕独立播放。
